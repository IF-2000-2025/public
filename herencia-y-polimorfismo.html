class Vehicle {
  private int speed;
  public void accelerate(int amount) {}
}

class Car extends Vehicle {
  private Engine engine;
  public void start() {}
}

• Herencia: class Car extends Vehicle
• Composición: atributo cuyo tipo es otra clase registrada (p.ej. Engine engine;).

class Vehicle {
  speed : int
  +accelerate(amount : int) : void
}

class Car extends Vehicle {
  engine : Engine
  +start() : void
}

• Herencia: class Sub extends Super
• Composición: atributo cuyo tipo coincide con otra clase registrada.
