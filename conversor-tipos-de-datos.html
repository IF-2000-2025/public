🔢 Java Casting Visualizer

Convierte números decimales y observa cómo se representan en diferentes tipos de datos Java

📊 Tipos Enteros

byte: 8 bits (-128 a 127)

short: 16 bits (-32,768 a 32,767)

int: 32 bits (-2,147,483,648 a 2,147,483,647)

long: 64 bits (rango muy amplio)

🌊 Tipos Flotantes

float: 32 bits (IEEE 754)

double: 64 bits (IEEE 754)

Formato: [Signo][Exponente][Mantisa]

🎨 Leyenda de Colores

Rojo = Bit de signo

Verde = Exponente

Azul = Mantisa
